Headless GL harness (dev tool): `node tests/tools/gl-measure.mjs capture <dir>` renders every level from fixed cameras (cameras.mjs: the spawn and destination views follow each level's real spawn and goal, `far` looks at the middle of the run) in headless Edge, with the far plane, sky and sun shadow set up as the game does (a level's far plane is its fog distance plus 40 m) (writes PNGs plus in-view draw calls / triangles to `<dir>/stats.json`), and `node tests/tools/gl-measure.mjs diff <dirA> <dirB> <outDir>` compares two captures pixel by pixel (needs Edge; set `EDGE_PATH` if it is not in the default Windows location).
