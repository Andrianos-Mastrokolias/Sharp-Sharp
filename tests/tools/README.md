Headless GL harness (dev tool): `node tests/tools/gl-measure.mjs capture <dir>` renders every level from four fixed cameras in headless Edge (writes PNGs plus in-view draw calls / triangles to `<dir>/stats.json`), and `node tests/tools/gl-measure.mjs diff <dirA> <dirB> <outDir>` compares two captures pixel by pixel (needs Edge; set `EDGE_PATH` if it is not in the default Windows location).
